# RCB Player Auction Analysis – SQL

## Problem Statement
RCB is looking to identify top-performing and reliable players for the 2017 mega auction while considering on-field performance and value for money.

**Objectives**
- Identify high-performing and consistent players
- Evaluate batting, bowling and player versatility
- Analyse team and venue performance
- Identify factors affecting match outcomes
- Develop data-driven auction strategies

## Dataset
IPL database with matches, ball-by-ball deliveries, players, teams and venues.

## Tools & Techniques
- SQL (joins, aggregations, CTEs, subqueries, window functions)
- Player, team and venue level analysis

## Key Insights
- RCB's performance has been inconsistent across seasons, so the squad needs to be more reliable and stable.
- Consistent performers should be prioritized over players who are strong in only one season.
- Top batsmen are crucial for RCB's scoring strength, especially in high-scoring matches.
- Players who contribute with both bat and ball give the squad more flexibility and balance.
- Some players perform much better at particular venues, so venue should influence selection.
- RCB should make the most of its home advantage and improve its away record.
- Bowling needs equal attention, because stronger batting alone won't win matches consistently.

## Conclusion
Mega-auction investments should be data-driven, combining performance, consistency, versatility, venue suitability and overall team impact to get better value for money.
